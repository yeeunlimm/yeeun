# 서울 팝업 후보 분석기

현재 단계는 데이터를 안전하게 모으고 점검하는 Python 기반 초안입니다. 과거 시간대별 유동인구와 팝업 실적 정답 자료가 준비되기 전에는 ML 모델을 학습한 것처럼 결과를 만들지 않습니다.

## 필요한 데이터

### 지금 사용 가능한 자료

- `서울시 문화행사 정보.csv`: 행사명·기간·장소·자치구·좌표·상세 URL이 있어 주변 행사와 팝업 이력을 찾는 데 사용합니다. 팝업 전수 목록이나 방문객/매출 자료는 아닙니다. 원본 파일을 저장소에 복사하지 말고 경로를 실행 옵션으로 전달합니다.
- 서울 실시간 도시데이터: 지원하는 주요 핫스팟의 실시간 인구 범위, 성별/연령 비율, 갱신 시각. 과거 시간대 기록은 이 API의 현재 응답만으로 소급할 수 없습니다.
- 기상청 중기육상예보: 서울·경기 권역의 먼 날짜 날씨/강수 가능성. 야외 위험의 사전 참고용입니다.

### 실제 유동인구 모델을 만들 때 필요한 과거 자료

최소 한 행이 `장소 × 날짜 × 시간대`를 나타내는 CSV가 필요합니다. 가능한 한 최근 1년 이상, 여러 장소와 계절의 관측치를 사용합니다. `data/templates/historical_footfall.csv`에 기대하는 열을 적었습니다.

- 타깃: 같은 공간 범위·같은 시간대에 측정한 실제 보행/체류 인원
- 예측 입력 후보: 날짜/요일/휴일, 날씨, 장소 ID, 20대/30대 구성, 교통 접근성, 확인된 주변 행사
- 선택 자료: 과거 팝업 방문객 수/POS 집계. 이것이 있어야 팝업 입장객이나 매출을 직접 예측하는 별도 모델을 만들 수 있습니다.

행사 성과 기록 양식은 `data/templates/popup_outcomes.csv`에 있습니다. 행사 종료 후 방문객 카운터와 POS의 시간대별 방문 수·구매 건수·순매출·판매량을 같은 시간 단위로 기록합니다. 개인정보는 저장하지 않습니다.

## 필요한 API와 권한

1. **서울시 실시간 도시데이터**: 사용자가 발급한 서울 열린데이터광장 키. `citydata` 이용 신청/권한이 있어야 하며, 조회 가능한 주요 핫스팟만 사용할 수 있습니다.
2. **기상청 단기예보 + 중기예보**: 공공데이터포털 서비스키와 각 서비스 활용 신청/승인. 짧은 기간은 격자별 단기예보, 더 먼 날짜는 중기육상예보를 사용합니다. 같은 서비스키를 쓸 수 있는지는 포털의 서비스별 승인 상태로 확인합니다.
3. **서울시 상권분석 유동인구**: 도로/건물 단위의 과거 시간대·요일·연령 자료를 우선 확보합니다. 정확한 공간/시간 해상도와 CSV 다운로드/오픈API 사용 가능 여부는 후보 주소를 정한 뒤 확인합니다.

`.env.example`을 `.env`로 복사한 뒤 새로 발급한 키를 `.env`에 넣으면 수집기가 자동으로 읽습니다. `.env`는 `.gitignore`에 등록되어 Git에 올라가지 않습니다. 기존에 채팅으로 보낸 키는 재발급하는 편이 안전합니다. 키를 코드에 직접 적거나 저장소에 커밋하지 마세요.

```powershell
Copy-Item .env.example .env
# 메모장 등으로 .env를 열어 두 키의 값을 입력합니다.
notepad .env
```

유튜브 댓글 분석은 브랜드/상품군 또는 후보 영상 범위가 정해진 뒤 선택합니다. 핵심 장소·날짜 분석에는 댓글이 필요하지 않습니다. 댓글 표본을 직접 제공하면 수집 API 없이 분석할 수 있고, 여러 영상에서 재현 가능하게 수집하려면 YouTube Data API 키가 필요하므로 그때 요청합니다. 지금은 키를 요청하지 않습니다. 대기질은 서울 실시간 도시데이터의 측정값을 쓸 수 없는 후보가 정해진 경우에만 별도 AirKorea API를 검토합니다.

## 실행

먼저 PowerShell에서 이 프로젝트 폴더로 이동한 다음 아래 명령을 실행합니다.

```powershell
python seoul_popup_pipeline.py inspect-events --csv "C:\Users\Administrator\Downloads\서울시 문화행사 정보.csv" --start 2026-10-05 --end 2026-10-11
python seoul_popup_pipeline.py collect-seoul --area "조회할 서울시 핫스팟 이름"
python seoul_popup_pipeline.py collect-mid-weather --tm-fc 202609300600
python seoul_popup_pipeline.py collect-short-weather --base-date 20260930 --base-time 0500 --nx <격자X> --ny <격자Y>
```

응답은 `data/raw/` 아래에 수집 시각과 장소/예보 기준을 붙여 저장합니다. 키는 파일이나 로그에 저장하지 않습니다. 격자 좌표와 예보 발표시각은 실제 행사 주소와 조회 시각을 확인한 뒤 사용합니다.

## 현재 필요한 사용자 자료

- 서울 실시간 API에서 지원되는 장소 이름 목록(또는 응답 확인 후 고를 수 있도록 우선 후보 권역)
- 서울시 상권분석서비스에서 받은 과거 도로/건물 유동인구 CSV. 특히 날짜·요일·시간대·20대/30대 정보가 있는 자료
- 후보 장소가 정해지면 정확한 주소, 운영 가능일/시간, 대관비, 수용량, 우천 대안/실내 여부
- 과거 팝업의 시간별 실제 방문객 수/매출/POS 집계가 있다면 별도 파일 (없으면 팝업 성과 예측 ML은 학습 불가)

브랜드/제품은 아직 없어도 데이터 수집 코드와 공개 유동인구 기반 장소 후보 탐색은 시작할 수 있습니다. 온라인 소비자 반응 분석은 브랜드/상품 정보가 생기기 전까지 보류합니다.
